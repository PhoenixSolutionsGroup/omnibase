Generates a presigned S3 upload URL and creates per-object permissions in Keto.

## Authentication
- **Session Auth**: Requires JWT token via Cookie (`omnibase_postgrest_jwt`) or Header (`X-Postgrest-Token`)
- **Service Key Auth**: Requires X-Service-Key + X-User-Id + X-Tenant-Id headers

## Permissions
Any authenticated tenant member can upload files. On upload, OmniBase automatically creates an `owner` relation in Keto, granting the uploader read, delete, and make-public permissions on the file.

## Upload Process
1. Request presigned URL from this endpoint
2. Upload file directly to S3 using returned URL (PUT request)
3. File metadata is stored in the database and Keto tuples are created

## Response
The response includes an `id` field (UUID) which is the storage object identifier. Use this ID to share the file with other users via the permissions API.

## URL Expiration
Presigned URLs are valid for 15 minutes after generation.
