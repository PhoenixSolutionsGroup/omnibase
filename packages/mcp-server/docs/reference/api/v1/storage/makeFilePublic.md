Makes a storage object publicly accessible to any authenticated user, regardless of tenant.

## Authentication
- **Session Auth**: Requires JWT token via Cookie (`omnibase_postgrest_jwt`) or Header (`X-Postgrest-Token`)
- **Service Key Auth**: Requires X-Service-Key + X-User-Id + X-Tenant-Id headers

## Permissions
Requires `make_public` permission via Keto. By default, only the file owner or users with the `can_make_public` relation can make a file public.

## Effect
Once public, any authenticated user can download the file without needing a Keto relation or tenant membership. The operation is idempotent — calling it on an already-public file returns success.
