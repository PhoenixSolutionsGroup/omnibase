title: "Check"

## Usage

```bash
omnibase permissions check
```

## Description

Check if subject has permission

## Arguments

- `subject (required)`
  Subject (e.g., user:123 or just 123)
- `object (required)`
  Object (e.g., tenant:456 or just 456)
- `relation (required)`
  Relation (e.g., invite, delete, view)
