---
title: "Set"
---

## Usage

```bash
omnibase permissions set
```

## Description

Set a permission relation

## Arguments

- `subject (required)`
  Subject (e.g., user:123 or just 123)
- `object (required)`
  Object (e.g., tenant:456 or just 456)
- `relation (required)`
  Relation (e.g., owners, admins, can_invite)
