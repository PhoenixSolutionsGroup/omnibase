Generates a presigned S3 download URL with per-object permission checks via Keto.

## Authentication
- **Session Auth**: Requires JWT token via Cookie (`omnibase_postgrest_jwt`) or Header (`X-Postgrest-Token`)
- **Service Key Auth**: Requires X-Service-Key + X-User-Id + X-Tenant-Id headers

## Permissions
The requesting user must have `read` permission on the file. This is satisfied by being the file owner or having a `can_read` relation in Keto. Public files (`is_public = true`) skip permission checks entirely and are accessible to any authenticated user.

## Download Process
1. Request presigned URL from this endpoint
2. Download file directly from S3 using returned URL (GET request)

## Public File Fallback
If the file is not found in the requesting user's tenant, the endpoint checks for a public file with the same path globally.

## URL Expiration
Presigned URLs are valid for 15 minutes after generation.
