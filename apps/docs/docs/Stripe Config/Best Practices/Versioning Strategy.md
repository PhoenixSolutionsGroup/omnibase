# Versioning Strategy

Use semantic versioning to track configuration changes:

## Version Numbers

- **Major version** (1.0.0 → 2.0.0): Breaking changes, significant restructuring
- **Minor version** (1.0.0 → 1.1.0): New products or features, backward compatible
- **Patch version** (1.0.0 → 1.0.1): Bug fixes, minor adjustments

## Examples

```json
{
  "version": "1.0.0"  // Initial release
}
```

```json
{
  "version": "1.1.0"  // Added new "Pro" tier
}
```

```json
{
  "version": "2.0.0"  // Restructured all pricing
}
