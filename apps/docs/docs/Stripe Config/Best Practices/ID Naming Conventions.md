# ID Naming Conventions

Use descriptive, consistent IDs:

## Products

```json
{
  "id": "plan_tier_version"
}
```

Examples:
- `saas_basic_v1`
- `api_pro_v2`
- `enterprise_platform`

## Prices

```json
{
  "id": "product_interval_currency_version"
}
```

Examples:
- `basic_monthly_usd`
- `pro_yearly_eur`
- `enterprise_custom`

## Meters

```json
{
  "id": "resource_metric"
}
```

Examples:
- `api_requests`
- `storage_gb`
- `compute_minutes`
- `bandwidth_usage`
